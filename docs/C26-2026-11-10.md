# C26 negative-only deployment integration

`negative_deployment.py` implements the frozen0.20/offset3 negative-tail recipe
using the existing selected model's `score` and `negative_tail.merge` functions.
It verifies all bundle files and both fold manifests before use. Positive parent
strings, first candidates and all candidate identities are preserved. Queries
with mixed/unknown/absent polarity metadata have explicit exact-parent fallback;
homogeneous negative queries with fewer than3usable peaks likewise fall back
exactly. Mixed/unknown cases never enter the neural scoring path. Every category
is reported separately rather than called a known positive acquisition.

This is deployment integration for the existing six fixed C21/C24 groups; it
adds no model, checkpoint, coefficient or subgroup search. Only their single
source/model/recipe-frozen global winner may bind a selected manifest for release.
No model upload, kernel push, public submission or new performance metric occurs
in this work. C13mixed120 remains unconsumed, with its scores unread.
