## Scientific rationale

[Krzakala et al., MSAlign, arXiv:2605.19752v2](https://arxiv.org/abs/2605.19752v2),
sections 3, 4 and appendix B.2, motivates chemically selected candidate negatives,
fusion of complementary scorers, and explicit separation of fitting from evaluation.
The proposed experiment uses the existing spectrum transformer and Morgan fingerprint
encoder, not the DreaMS/MolDeBERTa architecture. It tests one implication of the paper;
it is not a reproduction of MSAlign.

The current kit mixes in-batch retrieval with 16 hard negatives. Unrelated in-batch
molecules can often be rejected from mass alone. The experiment removes those
in-batch negative columns and uses 32 unique training-only near-mass/same-formula
negatives per query:

\[
L_{cand}=-\frac1B\sum_i\log\frac{\exp(z_i^T m_i/T)}
{\exp(z_i^T m_i/T)+\sum_{j\in H_i}\exp(z_i^T m_j/T)}.
\]

The auxiliary weighted fingerprint BCE, optimizer, augmentation, architecture,
temperature 0.1 and learning rate 0.0002 remain the kit's. This experiment changes
the retrieval objective and number of hard negatives together; it cannot isolate
their individual effects. Two independent initializations assess seed sensitivity.

Weighted BCE's population optimum has
`logit(q_j) = logit(p_j) + log(pos_weight_j)`. Therefore subtraction of
`log(pos_weight_j)` is a mathematically motivated calibration ablation. For a
Bernoulli fingerprint likelihood the candidate-dependent term is `fp @ logit(p)`;
the remaining log likelihood term is shared by all candidates of that query.
The correction is estimated from **training fingerprints only**. Imperfect calibration
and correlated bits mean this is a hypothesis, not a guaranteed improvement.

For fusion, standardize each model's score within the fixed candidate list and use
`(1-alpha)*z(public) + alpha*z(ours)`. The original public scorer alone decides the
leader with RRF weights 0.25/0.75; the blended score can reorder only the tail.
This directly tests a safer use of the new model than the submitted replacements.

## Preregistered two-round protocol

- RTX 2070 (8 GB), PyTorch **2.11.0+cu128**, CUDA runtime **12.8**, two PyTorch CPU threads,
  `.venv-gpu`; no local library-search or
  forward-simulation pipeline. Original `.venv` remains orchestration-only.
- Seeds **202611051**, **202611052**, each **32 complete epochs × 500 steps**, batch 96.
  Fixed final epoch, no best-epoch selection. Hold out the kit's validation identities
  completely from positives, auxiliary statistics and training negatives.
- Full kit diagnostic: up to 1000 validation molecules, truth plus 255 same-formula/
  near-mass known-structure decoys. MRR@25 is a retrieval diagnostic, not Kaggle MRR.
- Full 120-molecule labelled pipeline panel: all identities asserted absent from
  model training; fingerprint order checked exactly against the saved keys.
- Stable SHA-256 partition on molecule id: parity zero develops the fusion,
  parity one confirms it (**58 development / 62 confirmation identities**).
  No spectrum from one molecule crosses partitions.
- Round 1 sweeps alpha `{0, .1, .25, .5}`, fingerprint weight `{0,2}`, prior correction
  `{0,1}` on development identities only (16 configurations, including duplicates at
  alpha zero). Tie-break: smaller alpha, no correction, original fingerprint weight.
- Freeze that selected configuration before round 2. Round 2's grid is diagnostic
  only; it cannot change the selected configuration. Both confirmation scores use
  the frozen choice. They share molecules, so they are seed repeats, not independent
  molecular test cohorts.
- Paired molecule bootstrap, 10,000 draws, fixed seed 20261105. Local evidence passes
  only if both rounds improve confirmation MRR and both lower 95% bounds exceed zero,
  with at least 40 confirmation molecules and alpha greater than zero.
- These panel lists do not replay the fragment-check merge, outsider recovery or the
  frozen candidate generator. The panel is much easier than the hidden test and has
  already informed historical project decisions. It is not an untouched external test.
  No local number is numerically comparable to the submitted **0.477**. A passing
  proxy alone does not authorize a claim of a higher Kaggle score or automatic submission.

### Round 1 (seed 202611051)

Completed all **32 × 500 = 16,000** steps. Final 1000-molecule retrieval MRR@25
**0.612352**, top-1 **0.481**. The historical 32-epoch mixed-objective seed-3
holdout achieved MRR **0.577967**, top-1 **0.440** on the same kit diagnostic.
This is a different-seed comparison, not an isolated causal loss ablation.

Development selected `alpha=0.25`, fingerprint weight `2`, no prior correction.
Its MRR rose **0.915394 → 0.917241** on 58 development identities, but confirmation
MRR fell **0.910455 → 0.910399** on 62 identities (delta **-0.0000561**;
95% interval **[-0.0001683, 0]**, zero improved / one harmed).
All-120 panel MRR rises 0.912842 → 0.913706; that pooled gain includes the fitting
identities and **does not pass the confirmation gate**. Rank 1 remains fixed.
